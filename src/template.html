mdviewer

Open a Markdown file or a folder to begin.

Settings

Appearance

Sets the rendered document's font; headings, code, and tables scale with it. The editor and comment cards are unaffected.

Comments

New comments are written as <!-- GK: your note -->. The kinds add a suffix: -FIX, -Q, -NIT.

When a comment is addressed, the reply tag is … / CLAUDE: response -->. Comments from anyone using initials-style tags (<!-- AB: … -->) are shown too, so a shared file renders everyone's notes.

Line wrapping

auto matches the file's existing wrap width; a number (e.g. 80) forces it; 0 turns wrapping off. Edited paragraphs are re-wrapped to this width on save; the on-screen view always reflows to the window.

Unsaved changes

This file has edits in the viewer that are not on disk. Reloading takes the version on disk and discards those edits. Save the current version to a separate file first, or discard it.

How mdviewer works

Open a file

Open File picks a single Markdown file; Open Folder opens a collapsible file tree (click a folder to expand it; children load on demand). The picker starts in the last folder you used. Chromium browsers only.

Tabs

Every file you open gets its own tab; opening another does not replace the one you were reading. Click a tab to switch, or cycle with Ctrl+Tab. Close a tab with its × or ⌘W. Right-click a tab and choose Move to New Window (⌘⇧N) to read two files side by side; File → New Window (⌘N) opens an empty window.

Read

Documents render as GitHub Flavored Markdown with syntax-highlighted code. Toggle the file/outline sidebar with ☰ or ⌘B. Drag the thin bars between the panels to resize them; the widths are remembered. ⌘R (File → Reload from Disk) re-reads the open file from disk so an external edit shows up. If the in-memory copy has unsaved edits, it first offers to save them to a separate file.

Find

Press ⌘F to search the document. Type to highlight matches; ⏎ jumps to the next, ⇧⏎ the previous, Esc closes.

Edit

Click any block (paragraph, heading, list, table, code) to edit its raw Markdown in place. ⌘↵ or click away to save; Esc to cancel. Only the block you touched changes; everything else stays byte-for-byte identical, and changes autosave to disk (the toolbar shows Saved / Saving… / Unsaved).

Comment

Select text and click the ＋ Comment bubble, choose a tag, and type. The comment is written into the file right after the first word of your selection as <!-- GK: your note --> and shown as a card in the right margin, with that word highlighted. Click a card to edit or delete. Clear Comments removes them all at once.

Appearance

Open ⚙ Settings → Appearance to change the document font (system, serif, or monospace) and base font size. Headings, code, and tables scale with it. The setting is remembered across sessions.

Customize the tag

Open ⚙ Settings to set your own initials (e.g. AB) and the audit-trail responder. Kinds -FIX / -Q / -NIT colour the cards (amber / purple / gray). Comments from other people's initials render too, so files can be shared.

Line wrapping

If your .md files are hard-wrapped to a fixed column, mdviewer re-wraps edited paragraphs to that width when it saves (set it under ⚙ Settings → Line wrapping; auto matches the file). On screen the text always reflows to the window, ignoring the stored line breaks.

Export PDF

The PDF button (or ⌘P in the desktop app) exports a clean, light document with white margins. Comments are omitted from the PDF.
